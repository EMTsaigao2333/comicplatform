# 漫阅 - 原创漫画在线阅读分享平台

## 项目简介

**漫阅**是一个面向漫画爱好者的在线阅读分享平台，采用前后端分离架构（Spring Boot + Vue 3），参考哔哩哔哩漫画 UI 风格设计。支持漫画浏览、搜索、阅读、收藏、发布、管理等功能，适合作为 Java Web 课程设计或毕业设计项目。

---

## 功能模块

### 读者端

| 模块 | 功能 |
|---|---|
| 首页 | 公告栏、分类筛选、漫画搜索、热门漫画展示 |
| 分类页 | 按题材/地区/进度/收费多维度筛选漫画 |
| 漫画详情页 | 封面、简介、标签、章节列表、开始阅读 |
| 章节阅读页 | 滚动/翻页两种模式、键盘快捷键、章节导航 |
| 书架 | 收藏管理、按分类查看、继续阅读、移除收藏 |
| 登录/注册 | 用户认证，支持读者和作者两种身份 |

### 作者端

| 模块 | 功能 |
|---|---|
| 发布漫画 | 封面上传、基本信息填写、分类/地区选择 |
| 编辑漫画 | 修改已发布的漫画信息 |
| 章节发布 | 添加/删除内容页、设置发布状态 |
| 作品管理 | 查看自己的漫画列表、编辑、删除 |

### 管理员端

| 模块 | 功能 |
|---|---|
| 漫画搜索 | 按标题/作者搜索漫画 |
| 违规标记 | 标记/取消违规漫画 |
| 上下架管理 | 下架违规漫画或重新上架 |
| 分类管理 | 分类的新增、修改、删除、启停 |
| 公告管理 | 首页公告的发布、编辑、上下线、删除 |
| 评论管理 | 评论搜索、编辑、屏蔽/恢复、删除 |

## 技术架构

```

│              浏览器                   │
│    Vue 3 + Vue Router + Pinia       │
│    localhost:5173                    │
```

## API 接口一览

| 前缀 | 主要接口 | 功能 |
|---|---|---|
| `/api/user` | POST /register, POST /login, GET /{id} | 用户注册、登录、查询 |
| `/api/comic` | GET /page, GET /search, GET /author, GET /{id}, POST, PUT /{id}, DELETE /{id}, PUT /{id}/violation, PUT /{id}/status | 漫画增删改查、搜索、作者列表、违规标记、上下架 |
| `/api/chapter` | POST, PUT /{id}, DELETE /{id}, GET /{id}, GET /comic/{comicId} | 章节增删改查 |
| `/api/bookshelf` | POST, DELETE, DELETE, GET /user/{userId}, GET /check | 书架收藏管理 |
| `/api/category` | GET, GET /enabled, GET /{id}, POST, PUT /{id}, DELETE /{id} | 分类增删改查、启用分类 |
| `/api/notice` | GET, GET /published, GET /{id}, POST, PUT /{id}, DELETE /{id} | 公告增删改查、已发布公告 |
| `/api/comment` | GET, GET /comic/{comicId}, GET /rating/{comicId}, GET /{id}, POST, PUT /{id}, PUT /{id}/status, DELETE /{id} | 评论增删改查、按漫画查询、评分统计、屏蔽 |

## 数据库表设计（共 8 张业务表）

| 表名 | 说明 | 主要字段 |
|---|---|---|
| `t_user` | 用户表 | userid, username, password, usertype, phone, email |
| `t_comic` | 漫画表 | comicid, comictitle, author, category, coverimg, status, isviolation |
| `t_chapter` | 章节表 | chapterid, comicid, chapterno, chaptertitle, content, status |
| `t_chaptercontent` | 章节内容表 | contentid, chapterid, imgurl, displayorder, status |
| `t_bookshelf` | 书架表 | bookshelfid, userid, comicid, collecttime |
| `t_category` | 分类表 | categoryid, categoryname, description, sortorder, status |
| `t_notice` | 公告表 | noticeid, title, content, noticetype, publisher, publishdate, status |
| `t_comment` | 评论表 | commentid, comicid, userid, username, content, rating, status |
| `v_bookshelf` | 书架视图 | 联表查询书架+漫画信息 |

## 快速启动

### 后端

1. 导入 `comicplatformdb.sql` 到 MySQL
2. 修改 `application.properties` 中的数据库密码
3. IDEA 运行 `ComicplatformSpringbootwebApplication.java`
4. 启动后访问 `http://localhost:8080/api/comic/page` 验证

### 前端

```bash
cd comicplatform_vue/comicplatform
npm install
npm run dev
```

访问 `http://localhost:5173`

## 项目亮点

1. **前后端分离**：Spring Boot 提供 RESTful API，Vue 3 独立开发部署
2. **企业级代码规范**：VO/Entity 分层、统一 Result 返回、MyBatis-Plus Lambda 查询
3. **权限控制**：路由守卫 + Pinia 状态管理，读者/作者/管理员三角色
4. **哔哩哔哩漫画风格 UI**：深色导航栏、卡片式布局、沉浸式阅读
5. **灵活的图片策略**：开发阶段用 SVG 占位图 + AI 生成封面，后续可无缝替换
